# 发布视频任务

约 90 秒，1080p，可直接导出。真实使用录屏加等轴微缩场景，配乐由代码合成。

- [ ] V1 分镜与节拍：每个镜头的起止秒数、内容与对应节拍，整片按一个节拍网格剪
- [ ] V2 配乐：按节拍网格合成原创曲，WAV，无版权问题
- [ ] V3 真实录屏：六个应用各录真实操作（打开文件、编辑、导出等），1080p 以上，英文界面
- [ ] V4 等轴场景：用官网同一套渲染器逐帧导出（无头浏览器，固定帧时间），开场、转场与结尾
- [ ] V5 合成：录屏贴入等轴屏幕面或全屏，字幕中英，音画按节拍对齐
- [ ] V6 导出与核对：H.264 + AAC MP4，时长约 90 秒，逐段检查画面与声音
