# 官网任务

进度真相。从上到下逐条完成，每条完成后由 `scripts/review.sh` 交 codex 审查，通过才进下一条，每条最多五轮。

要求（用户 2026-10-09 定）：
- 整站是等轴 2.5D 微缩模型：无透视，统一等轴角度，平行线永远平行；体积只靠同一颜色在三个面上的明暗，不用投影；层级是高度，分类是区域，关系是道路与相邻；状态用具象小道具，不用抽象标签；组件像积木，有厚度，交互上浮或下沉一格；动效逐格生长、按节拍落位。
- 美学：标题粗、正文细且淡；留白约常规的 1.5 倍；90% 白灰黑，10% 单一强调色；无渐变、高饱和、霓虹与复杂卡片；无大框套小框，无无用说明与小标题；控件在用户表现出意图时才出现；以渲染结果为准，不以计算值为准。
- 地址 workers.dev；中英两种语言；Vite 8 + pnpm；文件不超过 500 行，注释一行十字以内，无 dead code，出错即暴露，不过度设计。

- [x] S1 工程骨架：`site/` 下 Vite 8 + pnpm、TypeScript、无框架；`wrangler.jsonc` 只用静态资源（`assets.directory`，`404-page`）；`pnpm build` 出 `dist/`，`pnpm preview` 可看；构建失败即报错 — R1 PASS
- [ ] S2 等轴几何：一种投影（真等轴，30°），无透视；积木由同一颜色的顶、左、右三面明暗构成，不用投影阴影；网格单位与高度单位；屏幕面（贴截图的平面）沿同一角度
- [ ] S3 首屏模型：一张桌面上的微缩模型，六个应用是六座积木建筑，按区域排布；高度表达层级；应用之间的真实连接（ElyMark→ElyTree、导出→ElyPDF）是道路；载入时逐格生长、按节拍落位
- [ ] S4 交互：积木悬停上浮一格、按下下沉一格；控件在悬停、聚焦或靠近时才出现；键盘可达，焦点可见；系统减少动效时不播放生长
- [ ] S5 六个区域：每个应用一个区域，真实截图贴在等轴屏幕面上，正文只写做什么；状态用具象小道具（离线、开源、本地文件）
- [ ] S6 中英两种语言：按浏览器语言选择，可切换；文案只在一处
- [ ] S7 下载与源码：链接 v0.1.0 发布页的六个 DMG 与源码包，写明 macOS 14、Apple Silicon、未公证的打开方式、AGPL
- [ ] S8 窄屏与无障碍：手机宽度无横向滚动，模型缩放而不变形；文字可被读屏读到；色彩对比达标
- [ ] S9 端到端测试：Playwright 核对首屏渲染、语言切换、全部外链可达、无控制台错误、减少动效
